# The Robot Vacuum's Best Excuse

> The crumb has been there 9 days. My map now routes deliveries to it. It ordered a smaller crumb.

One line: a robot vacuum's deadpan excuse for missing a spot — a concrete log fact (9 days on the map) plus one escalation that stays inside the robot's own logic.
